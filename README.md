# Raciocinio-Algoritmo
# 📘 Projeto de Introdução ao Git e GitHub

## 📖 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de aprender os conceitos básicos de **Git** e **GitHub**, utilizando ferramentas de versionamento de código que serão importantes nas futuras aulas de **Raciocínio Algorítmico**.

Durante o desenvolvimento, foram praticadas ações como:

* Criar repositórios;
* Fazer commits;
* Enviar arquivos para o GitHub;
* Atualizar versões do projeto;
* Organizar arquivos em um repositório remoto;
* Trabalhar com controle de versões.

---

## 🎯 Objetivo

O principal objetivo deste projeto é:

> Aprender a utilizar Git e GitHub para facilitar o desenvolvimento, organização e acompanhamento de projetos de programação.

Esse conhecimento será utilizado futuramente em atividades relacionadas à lógica de programação e raciocínio algorítmico.
